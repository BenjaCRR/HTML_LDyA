Para el diseño del portfolio busqué mantener una estética simple y agradable, utilizando principalmente tonos rojizos,
 blancos y grises. Que sirve tambien para marcar un buen contraste en el modo Claro-Oscuro (explico más abajo)

Las tarjetas de los proyectos tienen bordes redondeados y sombras para darle más profundidad a la página. 
También agregué diferentes animaciones y transiciones para que algunos elementos tengan movimiento al interactuar con
 ellos.
También agregué un botón en la barra superior para cambiar entre modo claro y modo oscuro

El portfolio está preparado para adaptarse a diferentes tamaños de pantalla.

Para conseguirlo utilicé principalmente Bootstrap y CSS, además de media queries y Flexbox.
De esta manera, las tarjetas, textos, imágenes y diferentes secciones se reorganizan para que la página pueda visualizarse correctamente tanto en una computadora como en dispositivos más pequeños.
